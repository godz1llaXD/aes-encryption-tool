
# AES Encryption GUI

A Python script using AES-256 for text encryption with a basic GUI.
Planned to evolve into a cross-platform mobile app.

## Features
- AES-256 encryption and decryption
- Simple graphical interface
- Secure key management (WIP)

## Usage
Run `main.py` to launch the application.

## Future Plans
- Convert to mobile app using Kivy or Flutter
- Improve GUI with animations and themes
- Cloud-based encrypted text storage (optional)
